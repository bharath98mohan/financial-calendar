# FinPlan - Financial Calendar

A modern personal financial planning and calendar web application to track SIPs, loan EMIs, salary credits, bank fixed deposits, and bond payouts.

## Features

- **Dashboard**: Monthly cash flow summary, total inflows vs. outflows, and net savings rate.
- **Financial Calendar**: Interactive monthly view displaying all upcoming credit and debit events.
- **SIP Tracker**: Track mutual fund SIPs, debit dates, and paused/active statuses.
- **EMI Tracker**: Monitor loan repayments, interest rates, tenure, and payoff progress.
- **Salary Management**: Keep track of monthly credit dates and employer details.
- **Bank FD & Savings**: Track fixed deposits, compounding frequencies, and maturity dates.
- **Bond Portfolio**: Track coupon rates, periodic payouts, and upcoming bond dates.

## Tech Stack

- **React** (Vite)
- **React Router** v6
- **Lucide React** (Icons)
- **Vanilla CSS**

## Getting Started

### 1. Install Dependencies
```bash
npm install
```

### 2. Run Locally
```bash
npm run dev
```

### 3. Build for Production
```bash
npm run build
```
